# 와끼리 · WOKKIRI

같은 크로스핏 박스 회원들이 자율적으로 여는 기간 한정 리그 모바일 웹입니다. 로컬에서 실행 가능한 MVP이며 공개 배포하지 않았습니다.

## 실행

Python 3.9 이상에서 추가 설치 없이 실행합니다.

```sh
python3 app.py
```

브라우저에서 [로컬 와끼리](http://127.0.0.1:8000)에 접속해 가상 시험 계정을 선택해 주세요. 첫 실행에 유형 불일치 예시가 있는 4명 리그가 생성됩니다. 시험 계정을 전환해 요청·답변·판정을 확인하실 수 있습니다.

기록과 사진은 `data/wokkiri.sqlite3`에 저장됩니다. 서버를 종료해도 유지되며, 서버 재시작 후 시험 계정만 다시 선택합니다. 다른 시험 DB는 `WOKKIRI_DB`, 포트는 `PORT` 환경변수로 지정할 수 있습니다. 서버는 로컬 주소에서만 접속할 수 있습니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
```

Node는 JavaScript 문법 확인에만 사용하며 앱 실행에는 필요하지 않습니다.
