# 와끼리 · WOKKIRI

같은 크로스핏 박스 회원들이 자율적으로 여는 기간 한정 리그 모바일 웹입니다. 로컬에서 실행 가능한 MVP이며 공개 배포하지 않았습니다.

## 실행

Python 3.9 이상에서 추가 설치 없이 실행합니다.

```sh
python3 app.py
```

브라우저에서 [로컬 와끼리](http://127.0.0.1:8000)에 접속해 아이디·닉네임·PIN 4자리로 가입해 주세요. 가입하면 복구 키를 한 번 보여 주니 저장해 두세요. PIN을 잊으면 이 키로만 계정을 되찾을 수 있습니다. 키를 놓쳤다면 로그인한 상태에서 리그 목록 아래 "복구 키 다시 만들기"에 PIN을 넣어 새로 받습니다. 친구는 시작 전 리그 화면의 "친구 초대"에 있는 링크나 QR 코드로 들어옵니다.

혼자 여러 역할을 시험하려면 가상 회원이 들어 있는 시험 모드로 실행합니다.

```sh
WOKKIRI_DEMO=1 python3 app.py
```

아이디/PIN garam/1111, narae/2222, daon/3333, raon/4444(닉네임 가람·나래·다온·라온)로 로그인할 수 있고, 첫 실행에 유형 불일치 예시가 있는 4명 리그가 생성됩니다. 가상 회원의 복구 키는 모두 `DEMO-DEMO-DEMO`입니다. 누구나 아는 값이라 배포 서버에서는 켜지 않습니다.

기록과 사진은 `data/wokkiri.sqlite3`에 저장됩니다. 서버를 종료해도 유지되고, 로그인도 1년간 유지됩니다. 이전 로컬 DB는 서버를 시작할 때 새 구조로 올라갑니다. 닉네임으로 로그인하던 계정은 더 로그인할 수 없고(아이디에 아무도 모르는 값이 들어가며 복구 키도 없음, 가상 회원만 위 아이디로 로그인), 시험 데이터는 DB를 새로 만드는 편이 낫습니다. 다른 시험 DB는 `WOKKIRI_DB`, 포트는 `PORT` 환경변수로 지정할 수 있습니다. 서버는 로컬 주소에서만 접속할 수 있습니다.

## 공휴일 표 갱신

새 리그 달력이 미리 빼 두는 공휴일은 `web/holidays.json`에 있습니다(지금은 2026-12-25 ~ 2027-12-27). 공공데이터포털의 공식 API로 갱신합니다.

1. [공공데이터포털](https://www.data.go.kr)에 가입하고 [한국천문연구원_특일 정보](https://www.data.go.kr/data/15012690/openapi.do)를 활용 신청합니다.
2. 발급된 인증키를 환경변수 `KASI_SERVICE_KEY`로 넘겨 실행합니다. 인코딩된 키와 아닌 키 중 어느 것을 넣어도 됩니다. 키는 저장소에 넣지 않습니다.

   ```sh
   KASI_SERVICE_KEY=발급받은키 python3 scripts/holidays.py --dry-run 2028   # 바뀔 내용만 보기
   KASI_SERVICE_KEY=발급받은키 python3 scripts/holidays.py 2028 2029        # 그 해들만 새로 채움
   KASI_SERVICE_KEY=발급받은키 python3 scripts/holidays.py                  # 연도를 안 주면 올해와 내년(한국 시간)
   ```

3. `git diff web/holidays.json`으로 확인한 뒤 커밋합니다.

한 달에 한 번 돌리기를 권합니다(임시공휴일·대체공휴일이 중간에 생기면 다음 실행에서 반영됩니다). 새 리그를 열기 전에 한 번 돌려도 됩니다. 크론 예시(매달 1일 09:00, 키는 본인만 읽을 수 있는 저장소 밖 파일에 `export KASI_SERVICE_KEY=...`로 둡니다):

```sh
0 9 1 * * . "$HOME/.wokkiri-kasi" && cd /path/to/wokkiri && python3 scripts/holidays.py >> "$HOME/wokkiri-holidays.log" 2>&1
```

요청한 해의 항목만 바꾸고 다른 해는 그대로 둡니다. 요청 실패, 오류 응답, 이상한 형식, 빈 결과가 하나라도 있으면 파일을 건드리지 않고 0이 아닌 코드로 끝납니다. 다만 연도를 주지 않은 실행에서 내년 공휴일이 아직 API에 없으면(보통 월력요항이 나오는 6월 전) 내년만 건너뛰고 그 사실을 한 줄로 알린 뒤 올해를 갱신하며, 건너뛴 해의 기존 항목은 그대로 둡니다. 올해가 비어 있거나 직접 지정한 해가 비어 있으면 오류입니다. 갱신은 그 뒤에 만드는 리그에만 영향을 주고, 이미 만든 리그의 날짜는 바뀌지 않습니다. 기간이 표에 없는 해에 걸치면 달력 위에 "N년 공휴일은 아직 반영되지 않았어요."가 보입니다.
