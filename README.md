# 와끼리 · WOKKIRI

같은 크로스핏 박스 회원들이 자율적으로 여는 기간 한정 리그 모바일 웹입니다. 로컬에서 실행 가능한 MVP이며 공개 배포하지 않았습니다.

## 실행

Python 3.9 이상에서 추가 설치 없이 실행합니다.

```sh
python3 app.py
```

브라우저에서 [로컬 와끼리](http://127.0.0.1:8000)에 접속해 아이디·닉네임·PIN 4자리로 가입해 주세요. 가입하면 복구 키를 한 번 보여 주니 저장해 두세요. PIN을 잊으면 이 키로만 계정을 되찾을 수 있습니다. 키를 놓쳤다면 로그인한 상태에서 리그 목록 아래 "복구 키 다시 만들기"에 PIN을 넣어 새로 받습니다. 친구는 리그 화면의 초대 링크로 들어옵니다.

혼자 여러 역할을 시험하려면 가상 회원이 들어 있는 시험 모드로 실행합니다.

```sh
WOKKIRI_DEMO=1 python3 app.py
```

아이디/PIN garam/1111, narae/2222, daon/3333, raon/4444(닉네임 가람·나래·다온·라온)로 로그인할 수 있고, 첫 실행에 유형 불일치 예시가 있는 4명 리그가 생성됩니다. 가상 회원의 복구 키는 모두 `DEMO-DEMO-DEMO`입니다. 누구나 아는 값이라 배포 서버에서는 켜지 않습니다.

기록과 사진은 `data/wokkiri.sqlite3`에 저장됩니다. 서버를 종료해도 유지되고, 로그인도 1년간 유지됩니다. 이전 로컬 DB는 서버를 시작할 때 새 구조로 올라갑니다. 닉네임으로 로그인하던 계정은 더 로그인할 수 없고(아이디에 아무도 모르는 값이 들어가며 복구 키도 없음, 가상 회원만 위 아이디로 로그인), 시험 데이터는 DB를 새로 만드는 편이 낫습니다. 다른 시험 DB는 `WOKKIRI_DB`, 포트는 `PORT` 환경변수로 지정할 수 있습니다. 서버는 로컬 주소에서만 접속할 수 있습니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
```

Node는 JavaScript 문법 확인에만 사용하며 앱 실행에는 필요하지 않습니다.
