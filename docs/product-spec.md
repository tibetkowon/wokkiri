# 와끼리 제품 기획 — 대화 최종 합의

이 문서는 사용자와의 기획 대화에서 최종 합의된 방향을 정리합니다. 별도 표기한 미정 사항을 확정된 요구처럼 구현하지 않습니다.

## 1. 목적과 범위

- 같은 크로스핏 박스 회원들이 자기들끼리 여는 기간 한정 리그 모바일 웹입니다.
- 실제 박스에서 즐겁게 사용할 무료 개인 프로젝트입니다. 사업성 검증, 수익화, 광고는 현 단계의 과제가 아닙니다.
- 코치 개입·승인이 필수인 공식 대회나 박스 운영 관리 시스템이 아닙니다.
- 유료 결제, 직원 초대형 회사 계정, 여러 박스 운영 플랫폼, 채팅, 영상 인증, AI 와드 해석, Scaled 중량 보정은 범위 밖입니다.
- 기술 스택은 미정입니다. 모바일 웹·DB를 작은 비용으로 운영하는 것이 목표이며 특정 인프라 사용은 확정되지 않았습니다.

## 2. 리그 유형과 일정

모든 시간은 한국 시간(Asia/Seoul)을 기준으로 해석합니다.

### 일상 와드 리그

- 시작일·종료일을 선택하고 집계 요일을 선택한 뒤 달력에서 날짜를 개별 추가·제외합니다.
- 주말·공휴일·박스 휴무일은 별도의 복잡한 조건식보다 최종 집계 날짜 목록으로 표현합니다.
- 하루에 비교할 와드는 하나입니다. 서로 다른 와드끼리 비교하는 기능을 만들지 않습니다.
- 집계일 다음 날 00:00에 일반 기록 등록이 마감됩니다.
- 집계하지 않는 날에는 미출석 점수도 없습니다.

### 지정 와드 리그

- 시작일·라운드 수·라운드당 기간(일)을 설정합니다. 3일·7일·14일 등 일 단위입니다.
- 라운드마다 와드 하나이며 라운드는 공백 없이 연속됩니다. 각 라운드와 전체 종료 일정은 자동 계산합니다.
- 라운드 종료일 다음 날 00:00에 일반 기록 등록이 마감됩니다.
- 점수는 하루마다가 아니라 라운드마다 한 번 부여합니다.
- **지정 와드에는 출석만/참여만이 없습니다. 반드시 기록을 등록해야 참여로 인정합니다.**

일정과 참가 명단은 시작 전에 확정하는 방향입니다. 시작 후 참가자 증감으로 N과 과거 점수를 바꾸는 동작은 피합니다.

## 3. 점수와 순위

- N은 리그 시작 시 확정한 전체 참가 인원입니다.
- 유효한 같은 유형 기록은 **Rx → Scaled → 출석만(일상 와드만)** 순서로 순위를 정합니다.
- 같은 수행 부문 안에서는 해당 기록 유형의 우열을 비교합니다. Rx 미완주도 Scaled 완주보다 먼저입니다.
- **개인별 Scaled 중량·밴드·대체 동작 차이는 보정하거나 별도 부문으로 나누지 않습니다.** 초보자의 개인별 조정도 Scaled로 참여할 수 있습니다.
- 출석만은 유효 기록 보유자 다음 공동순위입니다.
- 출석자의 등수가 해당 회차 점수입니다. 공동순위는 1, 2, 2, 4 방식입니다.
- **미출석/미참여는 상대순위가 아니라 고정 N점**입니다.
- 누적 점수가 낮을수록 종합 상위입니다. 별도 종합 타이브레이크는 정하지 않았으며 공동순위로 두는 단순한 구현을 우선합니다.
- 예: N=14, 정상 기록 8명·출석만 3명·미출석 3명이라면 각각 1~8점·공동 9점·각 14점입니다.

## 4. 와드 안내와 회원 기록

### 와드 안내

- 회원들이 당일 또는 해당 라운드의 운동이 무엇인지 확인하는 안내 자료입니다.
- 누구나 글·사진으로 등록·편집할 수 있고 변경 이력을 남기는 방향입니다.
- 안내에서 중량·타임캡·반복 수 등을 자동 추출해 기록을 검증하지 않습니다.
- Rx/Scaled도 참가자가 스스로 선택하고 잘못 등록한 것은 사람 간 이의 제기·정정으로 해결합니다.

### 기록 유형

와드당 회원의 최종 기록은 하나입니다. 복합 점수는 지원하지 않습니다.

| 유형 | 입력값 | 같은 수행 부문 안의 우열 |
|---|---|---|
| 시간형(For Time) | 완주 시간 또는 미완주 시 완료한 누적 반복 횟수 | 완주자 우선, 시간은 짧게. 미완주끼리는 완료 횟수가 많게 |
| AMRAP | 완료 라운드 + 추가 반복 횟수 | 라운드 우선, 같으면 추가 횟수가 많게 |
| 횟수형 | 총 반복 횟수 | 많게 |
| 중량형 | 지정 반복 횟수를 모두 성공한 최고 중량 | 무겁게 |
| 완료형(For Completion) | 완료 또는 실패 | 완료자는 공동순위, 실패는 같은 부문 완료자 다음 공동순위(출석만보다 앞) |

- 중량 단위는 **lb(파운드)**로 통일합니다. kg 환산을 추가하지 않습니다.
- 중량형 예: 3회 수행 기준일 때 90lb 3회 성공, 100lb 1회 성공이라면 90lb입니다.
- AMRAP을 총 반복 횟수로 환산하지 않습니다. 라운드·추가 횟수를 사전식으로 비교하면 됩니다.
- EMOM은 진행 방식이며 점수 단위가 아닙니다. 실제 기록에 맞는 유형으로 입력합니다.
- 타임캡 미완주는 완료한 반복 횟수로 기록합니다. 남은 횟수가 아닙니다.
- AMRAP은 시간이 끝났다고 미완주 처리하지 않습니다.
- 시간형 미완주 기록과 AMRAP 기록을 같은 유형으로 오인하지 않도록 합니다.

### 출석

- 일상 와드에서는 별도 출석 버튼/출석만 등록을 지원합니다.
- 기록을 등록하면 출석은 자동 인정하며 이후 기록을 추가해도 중복 점수가 생기지 않습니다.
- 지정 와드는 출석만을 지원하지 않습니다.

## 5. 자유 등록과 유형 불일치 — 가장 최근에 확정한 핵심 규칙

- 회원은 본인 기록의 유형을 자유롭게 선택해 등록합니다. 첫 등록자가 유형을 영구 고정하지 않습니다.
- 출석만/미참여는 기록 유형 투표처럼 세지 않습니다. 실제 제출 기록의 유형끼리 비교합니다.
- 같은 집계일/라운드에 실제 제출 기록 유형이 하나라도 다르면 **해당 회차 전체가 유형 불일치 상태**입니다.
- 특정 소수 회원을 틀린 사람으로 단정하지 않습니다. 날짜/라운드 기록 전체 상단에 불일치 안내와 유형별 인원을 표시합니다.
- 불일치 중 목록은 **회원 가나다순**입니다.
- **불일치 중에는 미출석 N점을 포함해 그 회차 전체 점수를 계산·누적 반영하지 않습니다.** 임의로 0점이나 출석 점수를 확정하지 않습니다.
- 이미 계산한 회차에 불일치가 생기면 기존 회차 점수를 누적에서 제외해 잠정 순위로 되돌려야 합니다.
- 유형이 하나로 일치하는 순간 순위·점수를 다시 계산하고 누적에 반영합니다.
- **불일치 상태에서는 일반 마감이 지나도 기존 기록 작성자가 본인 유형과 그에 맞는 기록값을 직접 수정할 수 있습니다.** 수정 이력은 남깁니다.
- 불일치가 해소된 뒤 마감 후 수정은 다시 정정 요청 절차를 따릅니다.
- 이 예외는 기존 기록 수정용입니다. 늦은 신규 등록은 지연 제출 요청이어야 합니다.
- 숫자를 다른 유형으로 자동 변환하거나 원래 기록을 자동 삭제하지 않습니다.

폐기된 제안: 다수 유형으로 점수를 계산하기, 소수 유형을 출석만과 같은 점수로 처리하기, 유형 동수 시 ABC순 첫 유형 채택하기, 첫 기록 등록 후 유형 잠그기.

## 6. 수정·지연 제출·이의 제기

- 일반 마감 전 본인 등록·수정은 자유입니다.
- 마감 후에는 본인 정정 또는 지연 신규 제출 요청을 합니다. 유형 불일치 중의 기존 본인 기록 수정은 위 예외를 적용합니다.
- 개설자도 남의 기록을 마음대로 수정할 수 없습니다.
- **모든 정정·지연 제출도 참가자 판정자 지정 방식**입니다. 개설자 전용 승인 모델은 폐기했습니다.
- 요청자는 수정 제안값/제출값과 사유를 제공합니다. 판정자는 요청자·대상 작성자를 제외한 리그 참가자 중 요청자가 지정합니다.
- 본인 정정·지연 제출은 본인만 제외합니다. 수락 절차 없이 지정 즉시 배정됩니다.
- 권한은 해당 요청·기록에만 열리고 처리 후 닫힙니다. 변경 전후·요청·답변·판정 사유를 기록하며 결과를 재계산합니다.

### 타인 기록에 대한 이의 제기

1. 신청자가 이의 내용과 정정 제안을 제출합니다. 판정자는 신청자가 당사자 둘을 제외하고 지정합니다(2명 리그는 지정 불가).
2. 기록 작성자가 수락하면 정정 내용을 반영하고 바로 종결합니다. 판정자는 개입하지 않습니다.
3. 작성자가 거부하면 거부 사유를 제출합니다.
4. 3명 이상 리그는 이의 내용·거부 사유가 지정 판정자에게 전달됩니다. 판정자는 유지·수정·무효를 결정합니다.
5. 2명 리그는 판정자가 없으며 **거부하면 기존 기록 유지 후 종결**합니다. 이의 제기 자체를 막거나 미해결로 남기지 않습니다.

별도 수락/양측 판정자 합의, 고정 대체 판정자, 개설자 특별 중재 권한을 추가하지 않습니다.

## 7. 종료와 요청 접수

- 마지막 집계일/라운드 기록 마감이 리그 기간 종료입니다.
- **기간 종료 후 3일(한국 시간 72시간)까지 신규 이의 제기·정정·지연 제출 요청을 받습니다.**
- 예: 12월 11일 00:00 기록 마감 → 12월 14일 00:00 요청 접수 마감(그 시각부터 신규 접수 불가).
- 접수 마감 후 새 요청은 불가합니다. 기존 요청의 답변·판정에는 기한이 없습니다.
- 유형 불일치 상태의 기존 기록 직접 수정은 마감 후 예외로 계속 허용하는 방향입니다. 접수 기간이 지난 뒤에도 불일치가 남아 있으면 해소 작업을 막지 않습니다.
- **최종 확정 조건: 신규 요청 접수 마감 + 모든 요청 종결 + 모든 회차 유형 불일치 해소.**
- 응답/판정 지연 또는 불일치가 남으면 최종 확정이 늦어질 수 있습니다. 강제 타임아웃/자동 패소는 넣지 않습니다.

## 8. 다음 설계에서 최소한으로 확인할 사항

아래는 아직 사용자와 명시적으로 확정하지 않았으므로 합의된 요구와 구분합니다. 스스로 결정 가능한 것은 단순한 기본값과 근거를 문서에 남기고, 점수·권한에 영향을 주는 모순만 사용자에게 확인합니다.

- 로그인 제공자, 초대/참가 UX와 닉네임 표시, 기술 스택·DB·무료 운영 구성.
- 최초 안내용 와드 생성 및 기록 부착 UI, 동일 집계일 중복 생성 방지.
- 누가 판정자로 지정될 수 있는지의 구현 권한, 요청 중복/충돌 시 처리. 판정자의 수정 허용은 해당 건으로 제한합니다.
- 2명 리그의 본인 정정·지연 제출은 남은 참가자 1명을 지정할 수 있습니다. 반면 타인 이의의 제삼자는 없습니다.
- 성공 중량/유효 횟수가 없는 경우의 점수 처리.
- 실제 기록이 하나도 없는 회차는 유형 불일치로 보지 않습니다. 일상 와드의 출석만/미참여 점수 계산 시점과 마감 전 잠정 표시를 명확히 합니다.
- 사진 허용 시 업로드 용량·형식·접근 권한·실패 처리. 외부 링크만으로 사용자 합의 없이 축소하지 않습니다.
- 기록 정정 요청의 원본이 불일치 직접 수정으로 바뀌었을 때 오래된 요청이 덮어쓰지 않도록 합니다.

## 9. 검증 우선순위

불필요한 테스트 나열보다 중요한 규칙에 작은 검증을 둡니다.

- Rx/Scaled 우선순위, 시간형 완주/미완주, AMRAP 라운드 비교, lb 최고 중량, 공동순위와 N점.
- 불일치 발생 시 기존 점수 제외, 불일치 해소 시 재계산, 출석만이 유형 불일치를 유발하지 않는지.
- 마감 경계, 종료 후 72시간 요청 접수 경계, 유형 불일치 중 마감 후 본인 수정 예외.
- 임의 타인 기록 수정 차단, 작성자 수락 즉시 종결, 거부 시 판정자 권한, 2명 거부 종결.
- 모바일에서 리그 참가 → 출석/기록 → 순위 → 요청/답변/판정 흐름.
